# Stage 8 — Curriculum foundation

ELL is a standalone English literacy website. Initial scope: published lesson listing, individual lesson reading, level/topic labels, measurable learning outcomes and text-based ISL performance guidance. Unpublished drafts return 404 and do not appear in listings.

The new migration removes legacy organisation tables and their membership data. Back up any real organisation data before migrating. Reversing the migration restores empty legacy tables, not deleted records.

Next: curriculum modules and units, lesson authoring permissions, ISL video media, visual exercises, reading/writing activities, learner progress and research-consent controls. No organisation or campus administration.
